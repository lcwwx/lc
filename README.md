# 墨忆 · Moyi

离线、单机、打开就能用的背单词应用。用 FSRS-6 安排复习，带每日计划、记忆曲线、学习热力图、图像记忆和例句朗读。

## 直接使用

打开 `index.html` 即可。所有学习数据保存在浏览器 `localStorage`，不需要账号，也不会上传服务器。

## 这是什么版本

这是**单文件分享版**：HTML、CSS、JavaScript、词库全部打包在 `index.html` 里。优点是发一个文件就能用，部署到 GitHub Pages 也只需要上传 `index.html`。
